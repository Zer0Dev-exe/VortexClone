🌀 Introducción a Cosmic

Cosmic es una recreación moderna, ligera y de alto rendimiento del reconocido bot de seguridad jagrosh/Vortex. Está diseñado sobre TypeScript y Sapphire Framework v5 con Discord.js v14, utilizando MongoDB Atlas en la nube y un panel de control web accesible en tiempo real.

Elimina por completo la necesidad de Java, dependencias de bases de datos locales en archivos (SQLite) y sharding innecesario para un rendimiento impecable sin lag ni bloqueos.

🔑 Permisos e Invitación

Para invitar a Cosmic a tu servidor con los permisos necesarios, utiliza el siguiente enlace oficial:

https://discord.com/oauth2/authorize?client_id=1550403576990531755&permissions=1099511627775&scope=bot%20applications.commands

Permisos requeridos por el bot:

  • Administrator (o individualmente: Manage Roles, Manage Channels, Kick Members, Ban Members, Moderate Members, Manage Messages, View Audit Log, Send Messages, Embed Links).
  • Jerarquía de Roles: Asegúrate de que el rol de Cosmic esté posicionado por encima de los miembros y roles que va a moderar en los ajustes de roles de Discord.

🛠️ Asistente de Configuración Rápida

Puedes configurar el bot en pocos segundos ejecutando el comando interactivo en tu servidor de Discord:

/setup

El asistente interactivo te guiará paso a paso para asignar:

  • Canal de Modlog (donde se registran sanciones con números de caso correlativos).
  • Canal de Serverlog (uniones, salidas y antigüedad de miembros).
  • Canal de Messagelog (mensajes borrados o editados).
  • Rol de Moderador y Rol de Silencio (Muted).

Alternativamente, puedes configurarlo todo de forma visual directamente desde el Dashboard Web.

🔨 Comandos de Moderación

Todos los comandos admiten ejecución por barra diagonal (/) y prefijo textual (>>):

Comando Sintaxis Descripción
/ban /ban <usuario> [tiempo] [motivo] Banea a un usuario (soporta tiempo temporal como 1h, 1d).
/unban /unban <id_usuario> [motivo] Desbanea a un usuario por su ID.
/kick /kick <usuario> [motivo] Expulsa a un miembro del servidor.
/softban /softban <usuario> [motivo] Banea y desbanea de inmediato para purgar sus mensajes del último día.
/mute /mute <usuario> [tiempo] [motivo] Aplica un aislamiento/timeout nativo o rol de silencio.
/unmute /unmute <usuario> [motivo] Retira la sanción de silencio.
/strike /strike <usuario> [cantidad] [motivo] Aplica strikes manuales y dispara la sanción configurada en la escalera.
/pardon /pardon <usuario> [cantidad] [motivo] Perdona o descuenta strikes de un usuario.
/clean /clean <cantidad> [filtro] [usuario] Purga masiva de mensajes con filtros (all, bots, links).
/check /check <usuario> Muestra historial de casos, strikes acumulados y antigüedad.
/reason /reason <caso> <nuevo_motivo> Modifica el motivo de un caso existente en la base de datos y modlog.
/slowmode /slowmode <tiempo> Ajusta el modo lento de un canal (ej. 5s, 1m, 0 para apagar).
/raid /raid <on|off> Activa o desactiva manualmente el modo de aislamiento / Anti-Raid.

🛡️ Comandos de AutoMod

Comando Sintaxis Descripción
/antiinvite /antiinvite <off|del|1|2|3> Configura la acción ante invitaciones de Discord no autorizadas.
/maxmentions /maxmentions <límite> Establece el número máximo de menciones permitidas en un mensaje.
/maxlines /maxlines <límite> Establece el límite máximo de saltos de línea por mensaje.
/autodehoist /autodehoist <carácter|off> Renombra automáticamente miembros con caracteres que alteran el orden alfabético.
/autoraidmode /autoraidmode <uniones> [segundos] Dispara el bloqueo automático si N miembros se unen en S segundos.
/filter /filter <add|remove|list> Administra palabras prohibidas y expresiones regulares (Regex).
/whitelist /whitelist <add|remove|list> Administra códigos o servidores autorizados en el filtro anti-invite.

⚖️ Sistema de Strikes y Escalado

El sistema de escalado aplica sanciones automáticas conforme un miembro acumula infracciones:

1 Strike  ➔ Advertencia (WARN)
2 Strikes ➔ Silencio temporal de 1 hora (TEMPMUTE 3600s)
3 Strikes ➔ Expulsión del servidor (KICK)
4 Strikes ➔ Baneo definitivo (BAN)

El programador interno en segundo plano (PunishmentScheduler) monitorea de forma atómica los silencios y baneos temporales, retirándolos automáticamente cuando expira su tiempo.

🌐 Panel Web & Discord OAuth2

El dashboard web se ejecuta en http://localhost:3000 y utiliza el protocolo oficial de autenticación de Discord:

  1. Haz clic en "Iniciar Sesión con Discord".
  2. Autoriza la aplicación con los permisos identify y guilds.
  3. El panel filtrará automáticamente los servidores donde eres Administrador o tienes permiso de gestión.
  4. Podrás modificar cualquier parámetro del bot en tiempo real con efecto inmediato.
